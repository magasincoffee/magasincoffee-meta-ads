# Experiments

Experiments document what is being tested, why, and what evidence will determine the outcome.

## File naming

`EXP-###-short-name.md`

## Experiment rules

- Write the hypothesis before launch.
- Identify the variable being tested.
- Define the control when applicable.
- Define the primary KPI before reading results.
- Avoid changing multiple major variables during the test.
- Record invalidation events.
- Preserve losing tests; failed experiments are useful knowledge.
