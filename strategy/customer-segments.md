# Customer Segments

Status: Draft

## Segment framework

Each target segment should include:

- segment name;
- customer need or job-to-be-done;
- geographic relevance;
- awareness level;
- likely offer;
- likely creative angle;
- exclusions;
- available first-party signals;
- confidence level.

## Audience principles

- Separate customer strategy from Meta targeting mechanics.
- Prefer broad targeting when the creative and conversion signal can do the filtering effectively.
- Use narrow interests only when there is a strategic reason.
- Retargeting should have a defined recency window and exclusion logic.
- Prospecting and existing-customer audiences should not be mixed without an explicit reason.

## Data note

Targeting options available in Meta can change. Re-check the live platform before translating a customer segment into an ad set.
