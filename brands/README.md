# Brand Registry

This repository contains two advertising brands that share one Meta Ads account.

## Brands

### Magasin Coffee
Path: `brands/magasin-coffee/`

Observed Instagram identity: `magasincoffee`

Use this brand for coffee/beverage/store-related campaigns.

### Magasin Cup
Path: `brands/magasin-cup/`

Observed Instagram identity: `th.xuonginlymagasincupcan`

Use this brand for plastic cup, printing, custom design, packaging, and B2B cup-sales campaigns.

## Separation rule

Every campaign, experiment, creative concept, performance review, and decision must identify its brand.

If a live Meta object cannot be confidently assigned, mark it `UNRESOLVED` instead of guessing.
