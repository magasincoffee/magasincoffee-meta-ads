# Performance Reviews

Performance reviews summarize what happened, why it may have happened, what remains uncertain, and what should be investigated next.

GitHub is not the canonical store for raw Meta Ads data. Pull current metrics from Meta Ads when reviewing performance.

## Cadence

- `weekly/`: tactical performance and experiment review.
- `monthly/`: broader strategic review and budget allocation assessment.

## Review principles

- Use the full requested date range.
- State the attribution setting when relevant.
- Separate observed facts from interpretation.
- Compare against approved KPI thresholds.
- Flag data quality or tracking uncertainty.
- Record actions only after they are approved.
